# JavaScript-структура

- `core/` — конфигурация, состояние, хранение данных и звук.
- `game/` — модель поля, расчёт размеров, canvas-отрисовка и игровой процесс.
- `ui/` — экраны, модальные окна, настройки и уведомления.
- `input/` — мышь, сенсорный ввод, клавиатура и пульт.
- `assistant/` — AssistantClient, обработка голосовых команд.
