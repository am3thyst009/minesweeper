# CSS-структура

`../app.css` — единый production-файл, подключаемый в `index.html`.

Файлы в этой папке повторяют логические слои CSS для чтения и сопровождения проекта:
- `00-tokens.css` — переменные, темы и базовые размеры;
- `01-base.css` — базовые правила;
- `02-layout.css` — структура экранов;
- `03-components.css` — компоненты интерфейса и игрового поля;
- `04-animations.css` — анимации;
- `05-responsive.css` — адаптация под размеры экранов;
- `06-smartapp-safe.css` — safe-area ассистента и модальные окна;
- `07-tv.css` — TV-режим и большие экраны;
- `08-focus.css` — фокус клавиатуры и пульта.
