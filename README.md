# Сапёр

Игра «Сапёр» для SmartApp / Salute.

Нужно открывать клетки, ставить флаги на предполагаемые мины и очистить поле, не взорвавшись.

## Возможности

- три уровня сложности;
- безопасный первый ход;
- флаги и режим флага;
- таймер;
- рекорды и статистика;
- пауза;
- звуки и музыка;
- голосовое управление;
- адаптация под мобильные экраны.

## Стек

HTML, CSS, JavaScript, Canvas.
